# Code of conduct

We want participation in this project to be safe, constructive, and welcoming.

Be respectful. Discuss ideas and behavior rather than attacking people. Do not
harass, threaten, discriminate against, or publish private information about
another person. Assume good intent while still giving direct, evidence-based
technical feedback.

Maintainers may edit or remove abusive, discriminatory, threatening, spammy,
or off-topic contributions and may temporarily or permanently restrict
participation when necessary to protect the community.

Report conduct concerns privately through the repository owner's GitHub
profile. Do not use a public issue when a report contains sensitive personal
information.
